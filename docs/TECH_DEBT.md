# Architecture debt register

Status values in the baseline table are `OPEN`, `PROVEN-DEAD`, `UNCERTAIN`, and `PLANNED`. The approved stabilization pass subsequently resolved the main ownership/state/dead-code findings; the table remains the original evidence register.

Implementation update (2026-08-30): TD-002, TD-005, TD-009, TD-010, TD-015–017, TD-020–023, TD-026, and TD-027 are resolved. TD-001, TD-003, TD-004, TD-006–008, TD-011–014, TD-018–019, TD-024–025 are structurally improved but remain partial until browser-based 7×7 visual regression is completed. TD-028 remains uncertain and intentionally preserved.

## Classified special cases

### Necessary domain rules

- Terrain has a persistent logical X/Z coordinate field and a separate camera family.
- Cube uses a seed topology and reversible cell formation.
- Chaos is intentionally two shells with independent layer phases plus internal binary matter.
- Terrain→Cube and Terrain→CORE require different compact target sizes/palettes; this belongs in the handoff contract, not an arbitrary destination check in a renderer.
- ERROR, CRITICAL, and CRITICAL_2 have different choreography parameters while sharing the CORE topology.

### Legacy architecture hacks

- `terrainExitBlocksCube`, Terrain writes to Cube fields, and `cubeTerrainHandoff`: they repair coordination between two FSMs rather than representing an owned primitive.
- `ribbonTopologyMotionAllowed`: it repairs the side effect of a generic cross-system rotation lock. The visible behavior—ribbons keep rotating until absorption—is required; the exception mechanism is not.
- `wasContainedDestinationRelease`, `alreadyContained`, and `alreadyPrepared`: manually synchronized entry history used because primitives lack input contracts.
- `terrainExclusive` and `terrainCubeSeed` visibility overrides outside coarse ownership: they compensate for an ownership model that does not represent Terrain/helpers.
- Long source/destination/phase chains that calculate Chaos scale and warmth: lifecycle is inferred from unrelated flags.
- Direct director activation/deactivation inside Terrain completion: transition code mutates final-state choreography.
- Opacity/emission/scale used as cleanup in addition to visibility: multiple gates emulate missing lifecycle ownership.
- Hard Terrain-return remap around `.68`: a special retarget path exists because arbitrary interruption cannot be represented.

### Uncertain; preserve until evidenced

- Exact ErrorDirector and CriticalErrorDirector recovery curves and whether any should visibly bridge same-topology state changes.
- Critical containment latch thresholds and damage-preview timing.
- Some hidden-clock advancement may be intentional for phase-continuous re-entry; choose policy only after behavior capture.
